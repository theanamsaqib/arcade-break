# Arcade Break

Snake, Breakout and Sky Bird in one Chrome popup. Free, no ads, no tracking.
Click the toolbar icon (or press **Ctrl+Shift+Y**) and play.

**[Download](https://github.com/theanamsaqib/arcade-break/releases/latest/download/arcade-break-extension.zip)** &middot; **[Website](https://theanamsaqib.github.io/arcade-break/)**

## Games

| Game | Controls |
|---|---|
| Snake | Arrow keys / WASD, Space to pause, R to restart. Optional wrap-around walls. |
| Breakout | Arrow keys / A D / mouse. Space to launch and pause. 3 lives, faster every level. |
| Sky Bird | Space, Up arrow or click to flap. |

Press **1 / 2 / 3** to switch games. Best scores are saved per game.

## Install (1 minute)

Works in Chrome, Edge, Brave and Opera.

1. Download the zip from the link above and **unzip it**.
2. Open `chrome://extensions` (Edge: `edge://extensions`).
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and pick the unzipped folder.
5. Pin the extension with the puzzle-piece icon, then click it to play.

If the shortcut doesn't work, set your own at `chrome://extensions/shortcuts`.

## Privacy

Arcade Break collects nothing. It asks for no permissions and makes no network
requests. Your best scores live in your own browser's local storage.
